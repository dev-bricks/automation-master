1. REPOSITORY AUDIT & DISCOVERABILITY BASELINE
================================================================================
- Organization: dev-bricks
- Umbrella Ecosystem: open-bricks
- Primary Category: Local-First Automation Governance, Event-Sourced Credit Budgeting & Reward Scoring
- Core Positioning: Private-by-default, local-first control and governance module for scheduled automations. Registers automation families, calculates explainable reward scores, assigns epoch-scoped credit envelopes, records immutable run receipts, and proposes throttling decisions.
- Distinct Value Proposition: Zero external runtime dependencies (`dependencies = []`). Eliminates unwanted background processes, network egress, and hidden cloud subscription costs. Employs an append-only SQLite event ledger with atomic `BEGIN IMMEDIATE` reservations to prevent double-spending and runaway loops without requiring complex cloud infrastructure.
- Sibling Ecosystem Integration: Interoperates via narrow, fail-closed contract adapters with task schedulers (`ellmos-scheduler`), deployment plan auditors (`system-gap-master`), offline multi-host replicators (`sqlite-transit-sync`), and AI coding agent repair engines (`companion-for-agy`, `safe-start-for-codex`).

2. TARGET PERSONAS & USER JOURNEYS
================================================================================
1. [PERSONA-01] Autonomous AI Agent Engineers & Multi-Agent Swarm Orchestrators
   - Needs: Govern autonomous scheduled tasks, prevent rogue agent loops, throttle excessive tool invocations, and enforce strict execution credit envelopes across local LLM agents (Claude Code, Antigravity, Codex, Kimi).
   - Pain Points: Uncontrolled agent execution causes token burn, infinite loops, and runaway resource consumption without centralized visibility or hold-backs.
   - Solution: Event-sourced credit envelopes, atomic reservations, and explainable reward policies that penalize repetitive failures and reward productive task completions.

2. [PERSONA-02] DevOps, SRE & CI/CD Pipeline Automation Architects
   - Needs: Regulate scheduled cron jobs, background runners, and recurring automation scripts across heterogeneous development workstations and servers.
   - Pain Points: Legacy crontabs lack holistic budget awareness; recurring jobs fail silently, compete destructively for shared CPU/disk resources, or drain resources during idle periods.
   - Solution: Narrow adapter seams for `ellmos-scheduler` and system schedulers, preflight NO_WORK checks (0 credits consumed), and offline multi-host sync via `sqlite-transit-sync`.

3. [PERSONA-03] Edge, Embedded & Air-Gapped Systems Developers
   - Needs: Reliable, zero-dependency task governance on air-gapped workstations, industrial controllers, and standalone edge devices.
   - Pain Points: Heavyweight workflow orchestrators (Airflow, Prefect, Temporal) require complex multi-container infrastructure (Docker, Redis, PostgreSQL) and constant internet connectivity.
   - Solution: 100% pure Python standard library (`dependencies = []`), single-file SQLite database, zero external daemons, and zero network egress (`INV-LOCAL-01`).

4. [PERSONA-04] Enterprise Security, Governance & Compliance Officers
   - Needs: Cryptographically auditable trace of all automated actions, resource usage, and governance decisions for internal compliance and external audits (SOC 2, ISO 27001).
   - Pain Points: Distributed log files are easily tampered with, lack payload integrity verification, and do not provide deterministic audit trails.
   - Solution: Append-only SQLite event ledger with SHA-256 payload hashes (`INV-IMMUT-03`), 30-day rich diagnostic projections, tamper-evident audit summaries, and formal 48h security SLA (`INV-ISOLAT-10`).

5. GOVERNANCE & RUNTIME INVARIANTS
================================================================================
- INV-LOCAL-01: 100% Local-First & Zero-Egress (offline, pure Python stdlib, zero network telemetry).
- INV-PRIV-02: Non-Elevation / RunAsInvoker (runs entirely in standard user mode without root/admin escalation).
- INV-IMMUT-03: Immutable Event Ledger (append-only SQLite `events` table with SHA-256 payload hashes; no UPDATE/DELETE on raw events).
- INV-ATOMIC-04: Atomic Reservation Integrity (SQLite `BEGIN IMMEDIATE` transactions prevent overdraft races and double-spending).
- INV-GATE-05: Fail-Closed Credit Gating (default SHADOW or DISABLED enforcement; explicit policy activation required for hard throttling).
- INV-NOWORK-06: Zero Cost for Inactive Runs (0 credits charged for NO_WORK, immediate hold release prevents idle budget depletion).
- INV-EXEMPT-07: Guaranteed Critical Exemption (protected baseline allowance for safety-critical jobs, health probes, and transit sync).
- INV-RETENT-08: 30-Day Receipt Retention Tiering (30-day rich diagnostic projections; immutable audit summaries for older events).
- INV-PARITY-09: Multi-OS Operating Parity (verified identical deterministic execution on Windows, Linux, and macOS).
- INV-ISOLAT-10: Cloud Sync Directory Isolation & 48h SLA (DB placed outside OneDrive/Dropbox in local state dirs; formal 48h security response SLA).
